# cv
curriculum vitae

This project is my cv.  

Everyone who visit my page cv.vladimirulasovets.de should be able to download my CV in three languages that I speak:
- German
- English
- Russian

. . . and for two roles:
- DevOps
- Support Engineer

The hook is the skippable "flappy bird" mini-game.  

Main goals:  
simple and fast as possible  
available on every browser including mobile  
GIT first, nothing is stored locally  

Tooling:
- Terraform (AWS)
- Ansible  
- Caddy webserver (easy, lightweight and no problems with certificates)  
- HTML + CSS for CV  
- JS for the game
